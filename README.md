# Zedu Whimsical Chat — standalone prototype

A responsive, static HTML/CSS/JS prototype for a professional-but-playful Zedu chat concept. It is isolated from `zedu-fe` and uses no backend or production credentials.

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Create a new GitHub repository, e.g. `zedu-whimsical-chat`.
2. Upload these files to the repository root.
3. In Vercel, select **Add New → Project** and import that repository.
4. Framework preset: **Other**. Build command: leave empty. Output directory: `.` (root). Deploy.

The message composer and reaction counters are local demo interactions only. No messages are persisted or sent to a server. Search, calls, and file uploads are illustrative UI controls.
